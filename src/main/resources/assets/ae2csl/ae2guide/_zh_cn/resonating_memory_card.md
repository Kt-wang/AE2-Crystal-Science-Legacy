# 谐振存储卡

<ItemImage id="ae2csl:resonating_memory_card" scale="3" />

**谐振存储卡** 与 AE2 记忆卡用法一致，但可保存 **9 份配置**，并记住当前选中的槽位。

## 用法

- **潜行 + 右键机器**：把机器设置保存到当前槽。
- **右键机器**：应用当前槽的设置。
- **潜行 + 滚轮**：切换槽位。
- **潜行 + 右键空气**（或非 AE 方块）：清空当前槽。
- **放置谐振样板供应器**：自动应用当前槽配置（方便连默认目标一起复制）。
