# Resonating Memory Card

<ItemImage id="ae2csl:resonating_memory_card" scale="3" />

The **Resonating Memory Card** works like AE2's Memory Card but stores up to
**9 configurations** and remembers which slot is selected.

## Usage

- **Sneak + right-click a machine** — save its settings into the current slot.
- **Right-click a machine** — apply the current slot's settings.
- **Sneak + scroll** — switch the selected slot.
- **Sneak + right-click air** (or a non-AE block) — clear the current slot.
- **Placing a Resonating Pattern Provider** — the current slot is applied
  automatically (useful for copying providers with their default targets).
