# 共鳴リンカー

<ItemImage id="ae2csl:resonating_linker" scale="3" />

**共鳴リンカー** は[共鳴パターンプロバイダー](resonating_pattern_provider.md)の
**デフォルト入力ターゲット**をその場で編集します。

## 使い方

1. プロバイダー（ブロック/パーツ）を**右クリック**してリンカーをバインドします。
2. 任意のブロック面を**右クリック**すると、選択中のデフォルト入力スロットの
   ターゲットとしてマークされます。同じ面をもう一度右クリックすると解除されます。
3. **スニーク + スクロール**でデフォルト入力スロットを切り替えます。

デフォルトターゲットは、共鳴パターンで個別にマークされていない入力と、
通常の処理パターン（入力インデックス順）に適用されます。
