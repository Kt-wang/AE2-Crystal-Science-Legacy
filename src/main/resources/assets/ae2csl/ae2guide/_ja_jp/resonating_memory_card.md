# 共鳴メモリーカード

<ItemImage id="ae2csl:resonating_memory_card" scale="3" />

**共鳴メモリーカード** は AE2 のメモリーカードと同じ操作に加えて、
**9 スロット**の設定を保存でき、選択中のスロットを記憶します。

## 使い方

- **スニーク + 右クリック（機械）**：現在のスロットへ設定を保存。
- **右クリック（機械）**：現在のスロットの設定を適用。
- **スニーク + スクロール**：スロット切り替え。
- **スニーク + 右クリック（空気/非 AE ブロック）**：現在のスロットを消去。
- **共鳴パターンプロバイダーを設置**：現在のスロットを自動適用します。
